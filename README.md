# Programación en Red

## Descripción

Repositorio que contiene todas las actividades, ejercicios y proyectos asignados durante el curso de **Programación en Red**. Este curso cubre los fundamentos de la comunicación de datos, protocolos de red, sockets y programación de aplicaciones cliente-servidor.

## Estructura del Repositorio

```
Programacion-en-red/
├── ejercicio1.py                    # Primer ejercicio del curso
├── ejercicio2.py                    # Segundo ejercicio del curso
├── ejercicio3.py                    # Tercer ejercicio del curso
├── README.md                         # Este archivo
└── 01-Actividad Práctica batalla naval TCP-UDP/
    ├── battleship_attack.py          # Cliente atacante (TCP)
    ├── battleship_attack_udp.py      # Cliente atacante (UDP)
    ├── battleship_defend.py          # Servidor defensor (TCP)
    └── battleship_defend_udp.py      # Servidor defensor (UDP)
```

## Contenido del Curso

### Ejercicios Básicos
- **ejercicio1.py**: Conceptos fundamentales
- **ejercicio2.py**: Ejercicio práctico
- **ejercicio3.py**: Ejercicio práctico

### Proyectos Prácticos
- **01-Actividad Práctica batalla naval TCP-UDP**: Implementación de un juego de batalla naval usando sockets TCP y UDP

## Requisitos

- Python 3.x
- Conocimientos básicos de networking
- Familiaridad con sockets y protocolos TCP/UDP

## Uso

Cada archivo o carpeta contiene instrucciones específicas sobre cómo ejecutar los programas. Consulta los archivos individuales para más detalles.
